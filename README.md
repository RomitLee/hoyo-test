# 梦幻西游背包监控

面向 Windows 的《梦幻西游》多窗口监控系统。从机在游戏电脑上识别背包、现金和面板状态，通过 HTTPS 将状态、告警和监控日志发送至服务端；电脑和手机均通过网页后台查看。

## 当前版本

2026 年 10 月 27 日将告警方式统一到网页后台的账号设置：手机推送、本机报警、电脑网页提示音、背包空格阈值、游戏币低额阈值、体力满提醒和商品售出提醒对该账号的所有从机一致生效。背包空格和游戏币低额提醒分别有启用开关与适用角色状态多选，默认仅对收货角色生效。体力满提醒默认关闭；开启后，属性面板实测已满或持续监控下到达预测满体力时间时提醒。商品售出提醒默认关闭；确认卖货摊位第一页在售商品数减少时提醒。游戏币阈值单位为万，默认 500，严格低于阈值时提醒；仅使用本次已确认读到的现金，回升后再次低于才重新提醒。在线状态与背包容量约每 5 秒更新，自动截图按设置的分钟周期独立执行。通信协议为 `1`。

| Windows 从机 | V2.14.6 | [下载从机 ZIP](https://jiankong.maipi.top/api/v1/updates/download/slave/V2.14.6) |

| Windows 主机（历史版本，不再使用） | V2.3.0 | 由网页管理界面替代 |

网页管理界面覆盖监控、现金、告警、从机管理、监控日志、截图和统一告警设置，可在电脑与手机浏览器使用。监控页宽屏每行展示五个窗口，点击画面可按账号 ID 翻看历史。设置页按账号配置 1～60 分钟自动截图周期，默认 5 分钟。截图从从机直传私有 COS，查看时提供 1 小时读取链接。旧版 H5 暂保留在 `/legacy`。电脑网页提示音需要浏览器允许声音且网页保持打开；关闭或休眠浏览器后，持续告警依靠服务端 Bark。

项目总后台 `/admin` 使用独立管理员权限，展示全站账号、设备运行状态和按游戏 ID 去重的角色信息，支持搜索、分页及按账号筛选。普通账号与旧版主机令牌均无法读取总后台接口。首次启用时由服务器运维人员在容器中运行 `python -m app.admin_cli grant 用户名` 授权一个已注册账号；撤销使用 `revoke`。总后台当前只读，不影响用户工作台的数据隔离。

从机 V2.14.0 新增“浏览他人收货摊位”识别：仅提取八类 1 级宝石的收购价，按区服、宝石种类及摊主 ID 去重上报。用户后台“商品统计 → 宝石统计”按区服展示有效摊主样本数、均价、最低价与最高价；同一摊主重复识别只更新其最新报价，不重复参与均价。

后续从机安装包存入私有腾讯云 COS 的 `releases/` 目录，服务端原下载路径返回临时 COS 直下载地址，因此现有从机自动更新器无需改动。当前已发布的旧包仍保留在服务器作为兼容入口。发布流程和权限范围见 [客户端安装包 COS 存储](docs/48-client-packages-cos.md)。

网页告警提示音使用与从机相同的 WAV 旋律，并在有待处理告警时循环播放；在设置页点击“允许当前浏览器播放”可试听。只更新云端网页，无须重新打包客户端。

角色卡片显示最近 30 天保存的截图总数；点击总数或画面可打开历史，第一张为最新截图，向右依次浏览更早的图片。此次网页调整只更新云端服务，不需要重新打包客户端。

本次客户端安装包位于 `dist-client-v2130/`。监控页按游戏 ID 汇总角色，跨从机浏览同一角色的截图；在线角色优先显示。角色首次被添加时会先在从机本地可靠登记，随后上报云端。截图仍只向所属后台账号开放。

上线与验证见 [游戏 ID 唯一角色卡片发布记录](docs/37-game-role-cards-release.md)。

事件触发的给予、交易截图现与周期截图合并展示在角色历史中，原监控日志截图入口保留；详见 [事件截图进入角色历史](docs/38-event-screenshots-in-role-history.md)。

从机可在打开属性面板时截图，并识别等级和体力值；网页按持续在线的恢复规则，每 5 分钟更新预计体力并预测满体力时间，同时保留上次实测值和观测时间。详见 [属性面板体力监控](docs/39-attributes-stamina-release.md)。

收货和卖货摊位分别识别，打开时截图并进入同一游戏 ID 的截图历史。角色卡片按本次监控中最近确认的摊位状态分为收货、出货、未知三组；卖货卡片展示第一页确认在售数量。详见 [摊位角色状态和售出提醒](docs/44-stall-monitoring-release.md)。

## 主要功能

- 每台从机手动添加最多 8 个游戏窗口，从标题解析区服、角色昵称和账号 ID。
- 识别背包打开、未满、接近满、已满及被游戏内面板遮挡的状态，支持 640×480 和 800×600 画面的既有检测流程。
- 读取背包现金，连续多帧一致后确认；保留最后确认时间，不可读时提示上次确认值。仅监控现金，不监控存银，不统计每日或每小时收支。
- 识别背包、给予、交易、属性、摊位、摊位记录和默认游戏界面；给予、交易面板可识别对方昵称和等级。
- 检测 Windows 窗口最小化和遮挡比例；遮挡、最小化等状态与背包容量告警分别处理。
- 网页后台分为“监控、告警、从机管理、监控日志”等板块。支持统一编辑从机名称、账号数据隔离、日志分页及按面板类型筛选。
- 网页设置支持账号级遮挡日志规则：是否上报、遮挡比例、连续检测时间，默认开启、60%、5 秒；服务端执行规则，设置跟随账号。
- 背包容量、游戏币低额、体力满和商品售出告警统一记录在云端；后台按账号控制手机 Bark 推送、本机报警和电脑网页提示音，从机不再单独选择告警去向。启动及运行期间会验证从机身份；验证失败或网络不可用时暂停监控，恢复验证后才能继续。
- 浅色界面；从机完整窗口为 560×1100，每行 3 个游戏窗口，保留 300×90 迷你模式、暂停/恢复、一键最小化和后台监控。

## 给予、交易自动截图

从机确认给予或交易面板打开时，保存识别所用的原始游戏窗口画面；确认交易对象变化时再次截图。不会截取整个桌面。同一面板持续打开不重复截图，首次补全对象信息合并到原打开日志，避免出现两条重复记录。

截图经设备认证上传至服务端，再存入私有腾讯云 COS。主机和 H5 的监控日志提供“查看截图”；旧日志没有历史图片，图片过期后仍保留文字日志。

- 上传失败每 30 秒重试，队列保存在 `runtime/screenshot-outbox/`，重启后恢复；成功后删除本地临时图片。
- 图片保留 30 天，待上传图片超过 30 天停止重试。COS 的实际删除由生命周期规则异步执行。
- 每张 JPEG 最大 2MB；截图上传不阻塞文字日志。
- 查看需登录且只能访问本账号日志，图片链接有效期为 1 小时。COS 长期密钥只配置于服务端。

详细行为与接口约束见 [截图功能说明](docs/29-panel-screenshots.md)。

## 安装与使用

1. 下载对应 ZIP，完整解压到独立目录，不要只复制 EXE。
2. 在[网页后台](https://jiankong.maipi.top/)注册或登录账号。
3. 新从机首次启动时输入同一账号和密码，机器会自动出现在网页“从机管理”中；后续启动使用本机设备凭据自动验证，不再输入密码。现有已配对机器可直接验证原凭据，保留后台修改过的名称。
4. 验证成功后点击“增加窗口”选择游戏窗口，保持背包完整可见。启动或更新重启后均需重新添加窗口。
5. 从机通常每 5 秒同步状态；电脑和手机使用同一网页后台。不同账号的数据相互隔离。

“后台监控”和迷你模式只改变从机界面显示，仍继续检测；“暂停监控”停止背包分析和告警。一键最小化先暂停监控，再最小化当前电脑上的游戏窗口，恢复窗口后需要点击开始监控。

现金和对象识别依赖画面可读性。被鼠标、聊天框或其他界面覆盖、界面缩放变化、最小化时可能无法识别。检测到面板打开不代表其所有文字一定可读。

## 自动更新与版本规则

程序启动约 1 秒后检查更新，之后每 10 分钟检查一次。下载后验证 HTTPS 来源、RSA-3072 签名、文件大小和 SHA-256，再由独立更新器安装并重启。检查或下载失败不会停止现有监控；安装期间监控会短暂停止。

更新保留整个 `runtime/`，包括账号会话、从机身份、设置、日志和截图待上传队列。新版本启动失败时，更新器支持回滚。升级后从机需要重新添加游戏窗口。

- 主机清单：`/api/v1/updates/latest/master`。
- 从机清单：`/api/v1/updates/latest/slave`。
- 旧共享入口 `/api/v1/updates/latest` 保留签名的 V2.1.0 过渡版本，旧客户端升级后进入各自更新通道。
- 主机与从机按通信协议判断兼容性，仅修改一端时只递增、构建和发布该端。
- V1.3.0 及更早版本使用的旧签名密钥已经更换，需要手动安装一次当前版本。

版本常量位于 `src/hoyo_analyzer/__init__.py`。签名私钥 `runtime/update-signing-private.json` 必须安全备份，禁止提交 Git、放入安装包或公开下载目录。独立发版与旧版过渡详见 [版本机制](docs/24-independent-client-releases.md)。

## 本地开发与验证

需要 Windows 10/11 和 Python 3.11 或更新版本。项目使用 uv 的开发依赖组：

```powershell
uv sync --group dev
.venv\Scripts\python.exe -m hoyo_analyzer.inventory_app
```

桌面测试：

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
$env:HOYO_PREVIEW_RELAY_URL = "http://127.0.0.1:9"
.venv\Scripts\python.exe -m pytest tests/test_inventory_app.py tests/test_master_app.py tests/test_relay_client.py tests/test_screenshots.py -q
Remove-Item Env:HOYO_PREVIEW_RELAY_URL
.venv\Scripts\python.exe -m pytest tests/test_auto_update.py -q
```

服务端依赖与测试：

```powershell
uv pip install --python .venv/Scripts/python.exe -r server/requirements-dev.txt
$env:PYTHONPATH = "server"
.venv\Scripts\python.exe -m pytest server/tests -q
Remove-Item Env:PYTHONPATH
```

## Windows 打包与发布

当前只发布从机客户端。打包默认只生成从机目录、从机 ZIP 和从机签名更新清单：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build_windows.ps1 -SkipInstall -OutputDirectory dist-client
```

历史主机源码继续保留，但日常需求不修改、构建或发布主机。现有签名格式仍包含历史主机包元数据；脚本从已签名的旧清单复用这部分元数据，不复制主机文件。构建脚本验证从机包大小、哈希和版本，生成从机签名清单、带版本号 ZIP、更新器和自检报告。复用目录需保留原签名清单；输出目录不要指向复用目录或正在运行的安装目录。

默认打包不带本机账号及配对凭据。`-IncludeLocalSettings` 仅用于私人调试，生成的包不可公开分发。安装包和构建产物不提交 Git。

发布时先备份、部署并验证服务端，再上传从机包，最后切换从机更新清单；保留历史主机清单和安装包，不覆盖旧版本字节。详细上线核对见 [本次发布记录](docs/30-screenshot-production-release.md)。

## 服务端部署

服务端使用 FastAPI、SQLite、Docker 和 Caddy，所有客户端主动发起 HTTPS 连接，无须在游戏电脑开放端口。部署步骤、认证接口和 COS 配置见 [服务端 README](server/README.md)。

截图需要服务端配置 COS 凭据及私有桶，并加载到容器环境；未配置存储时原监控和文字日志仍可用，截图暂存重试。新环境还需配置截图前缀的 30 天生命周期，以及使用自定义域名时的 DNS 和 HTTPS 证书。

## 识别技术与运行数据

背包和面板定位使用 OpenCV 模板及网格分析；现金使用数字模板和多帧确认；给予、交易对象字段使用本地 ONNX 中文 OCR 识别。当前产品不依赖 YOLO。OCR 模型随包分发，无需运行时下载，来源和许可见 [模型说明](assets/ocr/README.md)。

配置包括 `configs/default.toml`、`runtime/slave_settings.json` 等；本地事件位于 `runtime/events/inventory_events.jsonl`，启动错误见 `runtime/startup-error.log`，自动更新日志见 `updates/update.log`。切勿将运行目录作为通用安装包分发。

## 安全与限制

- 登录密码仅以 PBKDF2 摘要保存，设备通过独立凭据认证；截图查看按账号隔离。
- `runtime/`、`.env`、`.env.cos`、数据库、私钥及打包目录均不应提交。只有给予、交易的事件截图按上述规则上传，普通识别在本机完成。
- Windows Graphics Capture 无法可靠读取最小化窗口；背包需完整可见。更换分辨率或 UI 缩放后应先用实际截图验证。
- 现金识别不能准确推导所有交易收支，因此已移除每日和每小时统计。
- 强制结束进程、断电和崩溃不能保证产生正常关闭日志，离线仍由心跳超时判断。
- 自定义截图域名的 HTTPS 证书需要持续维护，COS 生命周期规则也需在桶中配置，程序不会代替云端自动创建这些资源。
