# hoyo-test

这是一个用于学习和验证以下技术链路的项目：

```text
视频/摄像头采集
→ OpenCV 图像处理
→ YOLO 目标检测
→ OCR 文字识别
→ 结构化数据
→ 状态机与大模型规划
→ 机械臂仿真及安全闭环
```

## 当前内容

- [零基础视觉识别与机械臂项目学习规划](./零基础视觉识别与机械臂项目学习规划.md)
- [Python 与 NumPy 10 天速学方案](./Python与NumPy十天速学方案.md)

## 项目原则

- 优先完成只读视觉识别和数据化 MVP。
- 机械操作只用于自建模拟界面或明确授权的测试环境。
- 大模型只承担高层规划，不直接控制机械臂关节和安全系统。
- 所有实际动作都必须经过白名单、状态机和安全校验。

## 当前状态

项目处于学习规划与技术验证阶段。
