# V2.1.0 本地预览（未上线）

## 试用入口

双击 `dist-v210-independent/启动本地预览.cmd`，等待数秒启动主机。本地预览使用独立 SQLite 数据库、测试账号 `preview210` 和模拟从机，不连接生产服务器，也不运行自动更新。页面副标题标记“本地预览”。关闭主机后，本地服务一同退出；重新启动会保留该测试账号的规则。

预览入口依赖此项目中的 `.venv` 和 `scripts/preview_monitor_logs.py`，请保留项目目录结构。普通主从机压缩包也位于 `dist-v210-independent/`，但尚未升级的正式服务器不能保存新规则；完整试用应使用上述入口。

## 遮挡日志规则

在主机“设置”中可配置：是否上报、遮挡比例（0～100%，含边界）和连续检测秒数（0～3600）。默认开启、60%、5 秒；0% 和 0 秒可恢复“任意正遮挡比例立即记录”的方式。

规则在服务端按账号保存，同一账号重新登录或在其他主机登录后同步。取消勾选仅停止新增遮挡日志，不删除历史记录，也不改变实时遮挡比例、最小化日志、面板日志或告警板块。

每个设备的每个窗口分别计时。连续观测达到比例与持续秒数后，按正常状态上报频率记录合格的遮挡日志。恢复到阈值以下、未知遮挡状态、暂停、最小化、移除窗口或超过 15 秒没有有效上报都会重建计时。修改规则后重建该账号的计时；重复上报不推进时间或重复存储，持续时间采用服务端时钟。原有从机通常每 5 秒上报一次，因此记录时刻受采样间隔影响。

## 类型筛选

支持全部类型、遮挡、最小化、开始监控、暂停监控，以及背包、给予、交易、属性、摊位、摊位记录和默认游戏界面。面板筛选包含该面板的打开和关闭记录。切换类型会回到最新页，“更早记录”保留筛选条件。查询先筛选再分页，较早的交易记录不会因为最近一页全是其他面板而丢失。

如果普通主机连接旧版正式服务器，只能在当前已取回的页面做类型预览，并明确显示“当前页预览”；账号规则显示“服务器尚未升级”。这些限制在本地预览服务中不存在，未来部署新版服务端后解除。
