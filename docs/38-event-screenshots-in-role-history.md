# 事件截图进入角色截图历史（2026-10-27）

云端服务升级为 2.16.1，网页后台同步更新。从机仍为 V2.7.0，主机仍为 V2.3.0，无需重打包客户端。

给予、交易等检测事件的截图在上传成功后，仍关联原监控日志，同时按游戏 ID 登记到角色的截图历史。角色卡片按**实际截图时间**显示最新一张图；周期截图、实时截图、事件截图共用这个时间顺序。延迟上传的旧图仍可在历史中查看，不会覆盖较新的卡片画面。事件截图不重置周期截图计时，因此 10:43:03 的周期截图之后若在 10:43:50 发生交易，卡片立即显示交易图，下一次周期截图仍可在约 10:53:03 发生。

上线时会把最近 30 天仍可访问、但尚未进入角色历史的旧事件截图补入。角色历史的访问权限继续按后台账号隔离；监控日志截图入口保留。仅在事件带有游戏 ID 时可关联到角色卡片。现有事件截图上传接口仍只接收给予与交易事件；未来扩展其他事件类型时可以沿用同一登记流程。
