# 识别日志（服务端 2.37.0 / 从机 V2.18.4）

2026 年 10 月 31 日：控制台新增「识别日志」页面，用于排查他人收货摊位识别率。服务端 `2.37.0`，从机 `V2.18.4`，协议 `1`。

## 页面

- 导航：实时监控之后新增「识别日志」（在「监控日志」旁）。
- 字段：时间、从机/角色、区服、摊主 ID、结果（识别 N 种 / 未识别到 / 识别失败）、识别到的商品与价格（带宝石图标）、查看截图。
- 实时：SSE 推送（`/api/v1/master/market-recognition-logs/stream`），新记录自动出现在顶部，无需手动刷新。
- 截图：复用面板事件的截图，点击按账号鉴权取签名链接预览。
- 保留：识别日志保留 7 天，启动时清理。

## 数据来源

从机每次完成一次他人收货摊位的 OCR（无论是否读出报价）都会上报一条：

- 成功：`status=ok`，带宝石名和价格；
- 一个字都没读出：`status=empty`，用于判断“打开了但没识别”；
- OCR 异常：`status=failed`。

服务端在保存时按设备 + 时间（±30 秒）关联最近的 `stall_other_buy` 监控日志，取得截图 ID；没有截图时页面不显示查看按钮。

## 接口

- `POST /api/v1/slave/market-recognition-logs`：从机上报（设备鉴权，`device_id + event_id` 幂等）。
- `GET /api/v1/master/market-recognition-logs`：账号鉴权，分页读取。
- `GET /api/v1/master/market-recognition-logs/stream`：SSE 实时推送。

## 验证

- 服务端测试 110 项通过，新增用例覆盖：上报、报价解析、幂等去重、空结果、截图关联。
- 从机测试 49 项通过。
- 本地端到端：页面加载历史记录，再用设备接口推一条新记录，2 秒内自动出现在列表顶部。
