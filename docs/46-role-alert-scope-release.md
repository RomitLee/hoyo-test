# 背包与游戏币告警的角色范围（2026-10-27）

网页后台“告警方式”将“背包剩余空格”和“游戏币低于”分别设置为独立开关与适用状态多选。可选状态为收货、出货和未知；两类告警默认开启且仅选择收货。阈值保留原值。关闭开关或角色状态不在所选范围时，不产生该类告警，也不触发手机、本机或网页提醒。体力满和商品售出提醒不受这两个范围设置影响。
