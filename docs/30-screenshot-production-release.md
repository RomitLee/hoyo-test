# 自动截图正式发布

2026年10月26日：主机V2.3.0、从机V2.2.0、服务端2.9.0，通信协议仍为1。

## 功能

给予或交易面板确认打开，以及确认对象变更时，保存识别所用的原始游戏窗口截图。上传失败在从机独立队列暂存并重试；不阻塞文字日志。首次OCR确认补全原打开日志，截图按日志去重。

主机监控日志增加“查看截图”按钮并在程序内预览；手机H5支持相同操作。旧日志无历史截图；过期图片显示过期，文字日志保留。

COS桶保持私有，只使用截图目录受限凭据。密钥仅在服务器，客户端不携带。查看接口按账号鉴权并提供5分钟HTTPS签名链接，图片保留30天。

## 自动更新

独立角色入口提供原有公钥可验证的schema3签名清单。主机V2.2.0自动升至V2.3.0，从机V2.1.0自动升至V2.2.0；当前版本不重复更新，不降级。原schema2、V2.1.0迁移桥保持不变，旧版可继续通过过渡版本进入独立更新通道。历史下载地址保留。

程序启动后及每10分钟检查更新，自动安装并重启。更新器保留整个runtime目录，因此配对配置和截图待上传队列均保留。从机重启后需要重新添加游戏窗口。

主机下载：`https://jiankong.maipi.top/api/v1/updates/download/master/V2.3.0`

从机下载：`https://jiankong.maipi.top/api/v1/updates/download/slave/V2.2.0`

包含原app、requirements、Compose、releases及SQLite一致性备份。旧镜像：`hoyo-relay-rollback:pre-screenshots-2.9.0`。仅增加截图表；优先保留线上数据库回滚程序，避免丢失部署后的日志。

COS配置文件为`/opt/hoyo-relay/.env.cos`，root所有、600权限，通过Compose环境注入服务端，不上传到Git或客户端。
