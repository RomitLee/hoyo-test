# 属性面板体力监控（2026-10-27）

从机 V2.8.0、云端 2.17.0、网页后台更新；桌面主机仍为 V2.3.0。属性面板打开时从机自动截图，原图关联监控日志并进入按游戏 ID 汇总的角色截图历史。截图事件不改变原有周期截图时钟。

从机以属性面板标题定位等级、体力标签和 `当前值/上限`，使用本地文字识别模型读取数字；标签、数字格式与连续画面均通过校验后才上报。已验证提供的两张 640×480 图片分别识别为 141 级、314/863 和 144 级、668/914；对图片进行 800×600 等比缩放后也能读出相同结果。异常、遮挡或不完整读数不会覆盖上次确认值。

服务端按 `每 5 分钟恢复 = ⌊上限×1%⌋ + ⌊等级×2%⌋ + 2` 计算。预测满体力时间为观测时间加上 `⌈(上限−当前值)/每次恢复⌉×5 分钟`。例如 141 级、314/863：每次恢复 12 点，需 46 次，即 230 分钟；北京时间 10:57:42 的观测对应预测 14:47:42。卡片展示观测值、恢复速度及预测时间；到达预测时间后以红字显示“体力已满（预测）”。

预测假设角色持续在线，且从观测时刻起以完整的 5 分钟周期估算；实际游戏恢复周期相位未知。角色离线后预测需复核，卡片保留最后确认的观测值，不会把推算值冒充新的实测值。体力记录按后台账号隔离，并按游戏 ID 关联角色卡片。
