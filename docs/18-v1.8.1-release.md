## 变更

- 移除主机“游戏币统计”页和每日、自然小时收支汇总，从机停止生成统计观测。
- 保留角色现金识别与窗口状态上报，连续三帧一致后确认；不可读时保留上次确认金额和时间。
- 不再识别、上报或展示存银。服务端忽略旧客户端上报的存银值。
- 服务端兼容旧版统计请求，确认接收后不再生成统计，查询返回空列表；保留历史数据库表。
- 修复缓存文件被 Windows 短暂占用时的未处理异常。保存失败保留内存队列、继续上报，每五秒重试，不阻塞界面。若磁盘持续不可写且程序被强制退出，未保存、未成功上报的数据仍可能丢失。
