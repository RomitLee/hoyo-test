## 功能

给予、交易面板对象昵称和等级使用离线OCR读取，并连续确认。打开面板及同一面板内切换对象都会写入监控日志，主机和H5显示结构化对象数据；失败时标记对象未识别，不复用上一位玩家。观察到面板不能证明给予成功或交易完成。

## 自动更新

独立入口 `/api/v1/updates/latest/master` 与 `/slave` 分别提供签名schema3清单。

旧入口继续提供签名schema2，版本V2.1.0：从机使用本次新包，主机使用此前已上线的V2.1.0原包。两个包实际版本均为V2.1.0，旧客户端无需理解独立版本也能安全过渡。从机V2.0.0自动更新至V2.1.0；主机V2.1.0直接走独立入口升级至V2.2.0；若主机还在V2.0.0，会先升到V2.1.0，再自动升至V2.2.0。当前版本不反复更新、不降级。

启动后和每10分钟检查更新。从机更新重启后需重新添加游戏窗口。

历史主机V2.0.0、V2.1.0及从机V2.0.0下载地址均保留。下载接口校验角色与实际版本，不能用slave/V2.2.0获取另一个版本的包。
