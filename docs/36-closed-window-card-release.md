# 退出的游戏窗口仍保留监控卡片（2026-10-27）

- 服务端 2.15.0、网页后台更新；从机仍为 V2.6.0，无需再次打包。
- 从机少报一个已监控的游戏窗口时，服务端保留原窗口记录并标记 `window_closed`。网页显示“已掉线”，保留最后截图与按账号 ID 查询的历史截图入口；实时截图按钮禁用。
- 掉线卡片不再展示陈旧的背包空格和遮挡百分比。同一角色以新窗口编号重新加入时，旧掉线卡片被新卡片替换，防止重复计数。
- 上线前已被旧逻辑删除的卡片，会从最近 30 天仍存在的窗口截图和角色日志中补回；无截图的旧窗口无法补回。
- 主动删除从机仍会移除该设备的窗口卡片。COS 截图依原有 30 天生命周期清理。

验证：服务端测试覆盖四窗变三窗、退出窗口最后截图与历史图读取、同角色重开后保持四张卡片，以及从旧截图恢复已消失卡片。生产环境也以临时账号完成前述端到端检查；临时账号及设备已清理，测试图由 COS 30 天生命周期清理。发布前备份位于 `/opt/hoyo-relay-backups/closed-windows-v215-20261027/`，数据库备份为容器数据目录中的 `closed-windows-v215-backup.db`。
