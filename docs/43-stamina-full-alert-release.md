# 体力满提醒（2026-10-27）

网页后台“设置 → 告警方式”增加账号级“体力满提醒”，默认关闭。开启后，两种情况合并为一种告警：属性面板截图的多帧识别值已经达到上限；或者根据最近一次实测值计算的满体力时间已经到达，且角色从实测到到时一直处于监控中。监控中断、窗口关闭或最小化后，旧预测失效，需重新识别属性面板建立预测基线。

服务端按角色的游戏 ID 与后台账号保存提醒状态。一个体力恢复周期只产生一次告警；预测提醒后再次截图实测已满不会重复。新的实测值低于上限时才重新准备下一次提醒。所有事件写入后台告警记录，显示“实测”或“预测”，并沿用账号的手机 Bark、当前设备报警和网页提示音三个开关。当前设备通过约 5 秒一次的状态回执领取并确认专属提醒；服务端重启后不会重复创建同周期事件。
