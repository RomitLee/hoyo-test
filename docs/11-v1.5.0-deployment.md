# V1.5.0 发布记录

日期：2026-10-20，北京时间。

## 已发布内容

- Windows 主机、从机：`V1.5.0`。
- 云端服务：`2.3.0`，手机 H5 同步支持七类面板识别日志。
- 公网入口：`https://jiankong.maipi.top`。
- 沿用 V1.4.0 签名密钥，未生成新密钥、未上传私钥。
- V1.4.0 启动约 1 秒检查，运行期间每 10 分钟检查并自动下载、校验、安装、重启。
- V1.3.0 及更早版本使用旧密钥，仍需手动安装一次当前版本。

## 验证

- 客户端 142 项、服务端 12 项测试通过。
- 用户提供的 80 张 640×480 图片分类通过；保留原生 UI 大小放置到 800×600 画布后追加 80 次通过。
- 主机、从机、独立更新器均完成打包自检，主机和从机实际 EXE 界面启动验证通过。
- 检查冻结模块及压缩包，确认识别模块和全部 10 张通用界面模板已打入从机。
- 两个角色的 ZIP 完整性、大小、SHA-256、RSA 签名、内置公钥及无账号/设备凭据检查通过。
- 使用 V1.4.0 完整包的隔离副本，验证新版本选择、相同可信公钥、应用替换、V1.5.0 界面启动健康标记、runtime 保留及回滚恢复旧 EXE。
- 在部署镜像内使用独立临时数据库验证六种面板写入、重传去重、角色归属、分页和账号隔离，未写入生产测试账号。
- 公网清单签名、V1.4.0 自动更新选择及两个 ZIP 下载入口验证通过。
- 发布后通过公网 HTTPS 完整下载两个 ZIP，重新计算 SHA-256 均与签名清单一致。
