# 面板事件日志截图

## 行为

- 从机在确认给予、交易、属性、我的卖货摊位、我的收购摊位或他人收货摊位打开时保存当前游戏窗口的原始画面（JPEG）；确认给予或交易对象变更时再保存一张。
- 网页设置的“事件触发截图”可分别关闭六类面板截图；关闭后事件日志仍正常上报，但不创建或上传截图。
- 六类开关按账号保存并由该账号的所有从机同步；自动周期截图和手动实时截图不受这些开关影响。
- 使用识别所用的同一帧，不抓取整个桌面，也不使用缩小的界面预览。
- 未识别对象也保留面板打开的截图。首次对象识别补全原日志，服务端通过已有的确认回执找到同一日志，不额外存储第二张截图。
- 同一面板持续打开不重复保存；真正换对象或关闭后重新打开会产生新日志和截图。
- 主机监控日志新增“截图”列，点击“查看截图”在程序内预览。手机 H5 日志支持相同操作。
- 旧日志和旧从机没有历史截图，显示“—”。截图过期后保留文字日志，显示“已过期”。

## 上传与隐私

- 从机只使用现有设备认证，通过 HTTPS 将 JPEG 上传给服务端；COS 长期密钥仅在服务端。
- 从机在 `runtime/screenshot-outbox/` 暂存截图和上传队列，失败每30秒重试，重启后恢复。成功后删除本地临时图；待上传图片超过30天停止重试。
- 截图上传队列独立于文字日志，截图故障不会阻塞日志上报。单张最大2MB。
- 服务端验证设备与日志归属、面板类型、JPEG内容和尺寸，禁止跨账号、跨设备访问。
- 服务端通过上传租约和日志唯一关联处理并发与重试。COS写入失败可重试，上传中断后的租约5分钟后可恢复。
- 对象路径为 `screenshots/{主机账号ID}/{日志ID}/{随机值}.jpg`，私有存储。
- 查看接口需主机登录，返回5分钟有效的HTTPS签名链接，响应禁止缓存。界面不会持有COS长期密钥。
- 图片上传后保留30天，沿用桶中截图前缀的生命周期规则；实际清理由COS异步执行。

## 配置与上线范围

服务端新增依赖 `cos-python-sdk-v5`、`Pillow`。环境配置：

```
COS_SECRET_ID
COS_SECRET_KEY
COS_BUCKET
COS_REGION
COS_SCREENSHOT_DOMAIN
```

线上已准备 `/opt/hoyo-relay/.env.cos`（root所有、600权限），Compose已配置下次重建时加载。
正式发布版本为主机V2.3.0、从机V2.2.0、服务端2.9.0，见 [发布记录](30-screenshot-production-release.md)。

旧客户端和服务端协议保持兼容：旧客户端继续上报原有日志；新主机查看旧日志不会要求截图。新从机连接未升级的服务端时，截图暂存重试，不影响原监控和日志。

## 验证

- 服务端测试覆盖截图上传与重试、首次OCR确认合并、真正更换对象、设备及账号隔离、无认证请求、损坏图片、超限图片、错误格式、过期访问、存储故障、上传租约恢复。
- 桌面测试覆盖原帧截图、触发条件、磁盘错误不打断识别、上传队列重启恢复、失败保留、成功清理、设备切换隔离、日志按钮匹配及过期状态。
- 实例化真实COS SDK并检查自定义域名签名，避免仅模拟存储无法发现SDK参数错误。
