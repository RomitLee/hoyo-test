# 监控卡片预计体力（2026-10-27）

网页监控卡片从最后一次属性面板实测体力出发，按 `min(体力上限, 实测体力 + ⌊经过分钟数/5⌋ × 每次恢复值)` 展示“预计体力”。页面每约 5 秒刷新时重新计算，因此经过整 5 分钟才增加一次。卡片同时保留“上次实测”和观测时间，避免把估算冒充新的截图读数。

角色已掉线时估算停在最后一次上报时间，并提示需复核。持续在线仍是预测前提；如果游戏内恢复周期与观测时刻并不同步，预计值和满体力时间可能与实际相差一个恢复周期，重新打开属性面板后会以新实测值校正。

网页体力边界测试 3 项和 TypeScript/Vite 构建通过。仅更新网页资源，服务端 API、从机 V2.9.0 和自动更新清单未变。上线前网页备份位于 `/opt/hoyo-relay-backups/stamina-estimate-20261027/`。
