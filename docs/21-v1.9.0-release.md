# V1.9.0 发布记录

## 界面与设备名称

- 主机、从机和手机 H5 使用白色卡片、浅灰背景与蓝色按钮，异常状态保持清晰的红/黄色提示。
- 主机保留监控、告警、从机管理、监控日志四个板块。监控、告警、日志统一显示从机名称，从机管理删除重复的设备编号列，编号仅在提示中保留。
- 主机在从机管理中编辑名称，从机顶部提供编辑名称入口。两端共用服务器上的名称；改名不改变设备身份、配对凭据或历史记录归属。主机按刷新周期同步，从机约每 30 秒通过心跳同步主机的改名。
- 从机完整窗口由 600×560 缩至 560×560，保留三列卡片和全部监控控制。六张卡片无需水平或垂直滚动，卡片展示现金、空格、置信度和遮挡状态；更多窗口可纵向滚动。
- 保留迷你模式、后台监控、现金多帧确认和上次确认提示，不恢复存银与收支统计。

## 兼容性与验证

主从机统一为 V1.9.0，输出目录 `dist-v190/`，沿用已有自动更新签名密钥。服务端升级为 2.6.0，新增仅允许设备修改自身名称的接口；旧客户端的配对、心跳、状态上报保持兼容，不修改数据库结构。

客户端 166 项测试、服务端 23 项测试和代码检查通过。覆盖改名后的多页面同步、主从机名称同步、设备权限隔离、旧心跳兼容、配置缓存与 560 宽度下六张卡片完整显示。

主从机成品启动、浅色主题、单一设备名称列、从机 560×560 尺寸及编辑入口自检通过；更新器、ZIP 完整性、签名独立验证与隐私文件检查通过。打包从机对六张实际截图的现金识别均正确。

服务端 2.6.0 部署后，在隔离测试数据库验证配对返回名称、从机改名、心跳同步、主机查看名称、现金上报和监控日志。生产数据库只读验证完整性及日志接口，未写入测试账号。

升级重启后需重新添加游戏窗口。手机页面刷新后获取浅色样式。
