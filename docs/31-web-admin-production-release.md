# Vue 网页管理界面上线

2026年10月26日，服务端升级至2.10.0；从机V2.2.0、Windows主机V2.3.0和通信协议1保持原版本。`https://jiankong.maipi.top/` 提供新的电脑与手机通用管理界面，旧H5保留在 `/legacy`。角色更新清单和签名包未改动。

## 范围

- 沿用现有FastAPI、SQLite、账号与从机认证，使用原域名同源访问API。
- Vue界面包含监控与现金、告警确认、从机管理、日志类型及面板筛选、截图查看、账号遮挡日志规则和Bark设置。
- 新增`latest=true`告警查询，仅供网页读取近期记录；现有默认顺序和旧客户端调用保持兼容。未处理告警另取最多500条并与近期记录合并。
- 电脑网页提示音需打开页面后主动开启，页面关闭或浏览器休眠时依靠服务端Bark通知。
- 网页源码在`web-admin/`，静态构建产物在`server/app/web-admin/`；Docker镜像随服务端打包，不增加Java、MySQL或Redis。
- 复用scaffold-master的浅色主题令牌、材质样式和Panel组件，保留其MIT许可证；没有引入GSAP。

## 部署与回退

线上先备份，再更新`app/main.py`、`app/database.py`和新静态目录并重建relay容器。备份位于`/opt/hoyo-relay-backups/web-admin-v210-20261026`，包含旧代码、SQLite一致性备份和旧镜像ID。旧镜像保留为`hoyo-relay-rollback:pre-web-admin-2.10.0`。数据库本次不新增表；需要回退时恢复旧代码和旧镜像即可，优先保留当前数据库和后续日志。
