# 窗口截图上线记录

2026年10月26日：从机V2.3.0、服务端2.11.0，Windows主机V2.3.0和通信协议1保持不变。

## 功能

- 网页监控页按窗口显示最近游戏截图、实际截图时间、现金与监控状态；点击图片放大查看。
- 账号设置中的自动截图周期为1～60分钟，默认5分钟。从机每5秒获取一次设置，监控暂停或游戏窗口最小化时停止定时截图。
- 每个窗口可点击“获取实时截图”，从机收到请求后截取下一帧，上传完成后网页自动打开新图。离线、最小化或45秒内未完成时显示失败，旧图不会被标成新图。
- 从机取得限定单个窗口对象的24小时上传链接并直接PUT到私有COS；同一链接可覆盖该窗口对象，不需要为每天每张截图申请链接。服务端只记录对象键、窗口关系与截图时间。读取时按账号鉴权签发5分钟链接。
- 截图对象位于`screenshots/live/`，沿用现有30天生命周期；持续监控时覆盖同一对象，停止更新后按最后修改时间清理。
