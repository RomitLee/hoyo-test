# V1.6.0 紧凑界面发布

发布日期：2026-10-20。

## 界面变化

从机完整界面由 800×632 缩小为 600×560，占用面积减少约 34%。角色卡片改为三列，缩小预览，保留角色名、背包状态、容量和遮挡/最小化信息。第 7、8 个窗口通过纵向滚动查看，不横向裁切。保留 300×90 迷你模式及后台监控。主机维持原有界面，版本统一为 V1.6.0。

## 发布与升级

沿用 V1.4.0/V1.5.0 信任的 RSA-3072-SHA256 密钥，私钥只在本地，不上传服务器和 GitHub。发布包不包含账号、配对身份、原始训练截图或私钥。

服务端仍为 2.3.0，本次只更新客户端包和签名清单，不重启服务。替换前备份旧包，签名清单最后切换。安装保留 runtime 设置和日志；重启后需要重新添加监控窗口。V1.3.0 及更早版本需要手动安装一次。

本次未修改下载超时、失败重试和断点续传行为，弱网下仍可能延迟升级。
