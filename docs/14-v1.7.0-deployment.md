# V1.7.0 游戏币识别发布

发布日期：2026-10-20。客户端统一 V1.7.0，服务端 2.4.0。

从机识别背包现金、存银，连续三帧一致后确认；主机在角色旁展示金额与确认时间。关闭背包或读取失败时保留上次确认值，非实时金额明确标记。保留 V1.6 紧凑界面、迷你模式、后台监控和既有监控日志。手机 H5 本次不增加金额展示。

识别边界见 [游戏币识别](13-money-recognition.md)：真实样本尚未覆盖数字 2、3、6、7，相关模板只通过合成验证，不能承诺这些数字在实际游戏中的准确率。

## 验证

- 客户端 147 项断言通过；Windows Qt 的混合测试进程在清理时出现过原生异常，改为分组运行（9+21+4+113）均通过且正常退出。
- 服务端 13 项测试通过；部署后的隔离数据库测试通过金额存取、配对、日志去重和账号隔离，未创建生产测试账号。
- 主机、从机打包程序依赖及实际 UI 启动自检通过；签名、压缩包完整性和隐私检查通过。
- 沿用原 RSA 更新签名密钥，V1.4/V1.5/V1.6 升级选择验证通过；V1.4 实包替换、V1.7 健康确认、runtime 保留和回滚验证通过。

## 部署

先备份源代码、旧镜像和在线 SQLite 数据库，再升级服务端；金额字段增量迁移，保留既有记录。客户端包完整上传并校验后，备份旧包，最后切换签名清单。私钥未上传服务器或 GitHub。

升级后需重新添加监控窗口；旧账号、配对、设置和日志保留。弱网下载延迟问题本次未改动。
