# 摊位角色状态和售出提醒（2026-10-27）

从机新增“我的收购摊位”模板，将收货和原有“我的摊位”卖货界面分开识别。两种面板连续确认打开时保存游戏窗口截图，沿用事件截图上传队列，成功后进入该游戏 ID 的统一历史截图列表。

每个游戏 ID 在所属后台账号内记录本次监控的最近摊位状态：看到收货界面为“收货”，看到卖货界面为“出货”，本次监控未见两者为“未知”。重新添加窗口、程序重启、暂停后恢复会生成新的监控会话并重置为未知；窗口暂时切回背包不清除已经确认的摊位状态。后台将三种状态分成独立板块，原有在线优先排序和离线截图保留。

在卖货界面，仅对物品类第一页的 5×4 格子读取右上角绿色在售对钩。数量连续稳定约 5 秒后才提交；切换类别或页面时不提交不完整读数。卖货卡片显示确认数量。账号级“商品售出提醒”默认关闭；开启后，同一监控会话内确认数量由 20 降到 19 等减少情况，生成一条“商品售出”告警。数量回升建立新基线；新监控会话首次读数也只建立基线。下降数量按售出处理，记录变化前后数量和减少件数，并沿用手机、当前设备和网页提示音三个开关。
