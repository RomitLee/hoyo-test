# 账号级告警设置（2026-10-27）

从机 V2.9.0、服务端 2.18.0。桌面主机程序停留在历史版本 V2.3.0；当前管理入口为网页后台。

后台“设置 → 告警方式”统一保存手机是否推送、当前设备是否报警、电脑网页提示音，以及背包剩余空格阈值。手机推送继续使用账号 Bark 密钥、连续呼叫和重复提醒间隔。容量告警始终写入后台告警记录，三个开关分别决定送达方式；即使本机报警关闭，也不会抑制后台记录或手机推送。

从机启动登录后及每次心跳从服务端同步本机报警开关和容量阈值，心跳周期约 30 秒。本机设置窗口只显示登录状态与后台设置提示，旧版本地告警档位不再参与决策。旧主机告警配置不再使用。现有 Bark 开关和密钥保留；新增的本机报警、网页提示音默认关闭，阈值默认 0 格。网页提示音由账号保存，但浏览器仍需一次用户操作允许播放，且需要网页保持打开。

服务端旧版 Bark 接口请求未带新字段时保留新字段原值，避免历史客户端覆盖后台设置。数据库在启动时补齐字段。构建继续复用历史主机包用于独立版本签名清单，不发布新的主机版本。
