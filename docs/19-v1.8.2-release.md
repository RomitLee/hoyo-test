# V1.8.2 发版记录

## 变更

- 将主机原“实时监控与告警”拆分为“监控”和“告警”两个独立板块。
- 主机页签顺序调整为“监控、告警、从机管理、监控日志”。
- 监控列表将现金金额与金额确认时间合并显示，金额为主要内容，确认时间为次要内容。
