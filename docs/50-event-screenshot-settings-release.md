# 账号级事件截图开关发布

2026 年 10 月 30 日发布服务端 `2.32.0` 和 Windows 从机 `V2.17.0`。本次新增账号级事件截图开关，使同一账号下的所有从机按网页设置决定六类面板是否生成并上传截图。

## 调整内容

- “监控与截图”标签页新增六个事件触发截图开关：给予、交易、属性、我的卖货摊位、我的收购摊位和他人收货摊位。
- 六类开关默认开启，按账号保存并通过现有从机控制接口同步到该账号的全部从机。
- 关闭某一类截图后，对应面板事件日志仍正常上报，但不创建本机截图、不写入上传队列。
- 自动周期截图、手动实时截图、截图历史和日志查看不受事件开关影响。
- 服务端为旧数据库自动补充六个开关列并默认开启；旧客户端不提交开关字段时保留服务端已有设置。
- 从机退出登录时清空旧账号的截图权限，避免后续账号错误使用之前的开关。

## 兼容性

- 通信协议保持 `1`。
- 服务端向后兼容不提交 `event_screenshots` 的旧从机；此时沿用该账号当前设置。
- 旧数据库升级不删除或重建现有设置表，新列由启动迁移补齐。
- 历史 Windows 主机包保持 `V2.3.0`，不参与本次构建。

## 发布顺序

1. 备份线上服务端源码、静态文件和容器镜像，构建并部署服务端 `2.32.0`。
2. 验证健康检查版本、数据库迁移、设置读写接口和网页资源。
3. 构建并自检 Windows 从机 `V2.17.0`。
4. 上传 ZIP 到私有 COS，校验对象后原子切换从机签名清单。
5. 验证公网清单、COS 临时下载链接和安装包 SHA-256。

## 回退

- 服务端回退前保留线上 SQLite 数据库；新增列可保留，旧版本代码会忽略这些列。
- 静态文件和 `main.py`、`database.py` 从部署前备份恢复，并将 `hoyo-relay-relay:latest` 切回发布前镜像。
- 从机清单从 `/releases/history/slave/V2.16.1/release-manifest.json` 恢复，已上传的 `V2.17.0` COS 对象保留，不覆盖其他版本。
