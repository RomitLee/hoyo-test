- 从机角色入口：`https://jiankong.maipi.top/api/v1/updates/latest/slave`，签名 schema3、V2.0.0。
- 原更新入口：继续返回原签名 schema2、V2.0.0，避免触发未改动从机更新。

旧客户端请求不包含程序类型，无法区分主机与从机。现有旧主机需要手动安装一次 V2.1.0，以后使用独立入口自动更新；现有从机无需升级、重新配对或重启。
