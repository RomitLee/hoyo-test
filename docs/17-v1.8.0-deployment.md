# V1.8.0 发布记录

发布日期：2026-10-20。客户端主机、从机统一 V1.8.0，服务端 2.5.0。

主机新增“游戏币统计”，以账号 ID 汇总北京时间自然日和自然小时的现金起始、补入、收购、结束金额，显示监控覆盖时间及未监控净变动。暂停、不可读、最小化或连接被判断离线后重建基线，跨中断差额不计为收支。统计细则见 [现金统计说明](16-cash-statistics.md)。

## 发布验证

- 客户端测试分组 10+21+14+114，共 159 项通过；Qt 单组在并行运行后清理时出现退出异常，串行复核全部 21 项通过并正常退出。
- 服务端 22 项测试通过，包含连续一日生成 24 个小时记录、没有观测的小时不填零、基线/补款/支出、中断恢复、跨日/跨小时、重传去重与账号隔离。
- 新部署服务镜像在隔离临时数据库中，通过 HTTP 验证 1000万起始+1000万补款-300万结束=1700万收购；重复请求不重复入账，中断后增加的余额不算补款；未写入生产测试账号或账目。
- 打包 EXE 的依赖、真实 UI 启动、主机统计页和两张统计表验证通过；最终从机 EXE 对6张原图金额均正确识别。
- 签名、安装包完整性、无账号私钥检查通过；V1.4～V1.7.1 升级选择验证通过。旧版实包文件替换、runtime 设置及日志保留、健康确认和回滚验证见本地 runtime/update-v1.8.0-smoke-report.json。

## 升级注意

先备份并升级服务端，再完整上传客户端包并校验，最后切换签名清单。沿用原更新密钥，未上传私钥。升级后需重新添加监控窗口并打开背包；从首个有效现金金额建立统计基线，旧版未记录的收支无法回填。H5 本次不增加统计页面。

金额收支只依据识别到的净变化，无法拆分两次识别之间同时发生的补款与收购。自动更新弱网下载延迟本次未修改。
