# 从机 V2.18.0：重启自动恢复窗口 + 收货价漏读修复

2026 年 10 月 30 日：从机 `V2.18.0`，服务端 `2.35.2` 不需要改动，通信协议 `1`。

## 1. 重启后自动恢复监控窗口

此前自动更新、手动重启或程序崩溃重开后，都要重新一个个添加游戏窗口。现在把窗口身份写进本地设置，启动后自动接回：

- 添加窗口时把 `title`、`role_id`（游戏 ID）、区服、角色名写入 `slave_settings.json` 的 `monitored_windows`，最多 8 条。
- 登录验证通过后 5 分钟内，每次扫描都会尝试恢复：优先按**游戏 ID** 匹配，匹配不到再退回**完整窗口标题**。
- 游戏重启后窗口句柄变化也没关系，仍按游戏 ID 找回；游戏窗口晚一点启动也能在窗口期内自动接上。
- 只有用户点面板上的「移除」才会忘记该窗口；游戏窗口关闭属于临时断开，保留记录，重开后自动恢复。
- 恢复的窗口沿用当前暂停状态，若程序处于暂停则恢复后仍是暂停，不会偷偷开始监控。
- 日志会提示「已自动恢复 N 个正在监控的游戏窗口（无需手动添加）」。

## 2. 收货摊位漏读价格

见 [收货摊位漏读修复](53-stall-price-ocr-fix.md)：价格掩码改用单元格主导色，避免滚动条、宝石图标、选中高亮把整行价格判读打掉。同一张线上截图从 7 类恢复到 8 类（补上 1 级太阳石 55,000）。
